Figure 1. Four independent edge-AI modules ingest local/cached data, run entirely on-device (offline) under privacy-by-design, and emit only kilobyte-scale derived telemetry that syncs when connectivity returns — feeding an administrative dashboard. Module 4 forecasts from open geospatial/weather data alone; no module depends on another, and no IoT hardware or on-trail connectivity is required.
